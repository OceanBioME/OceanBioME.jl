Sinking and dissolving particles in two-dimensional turbulence

In this example we release mineral particles at the surface of a two-dimensional turbulent flow, as might be done for ocean alkalinity enhancement. The particles sink and dissolve, releasing alkalinity into the water.

We first release hydrated lime (calcium hydroxide) with the default parameters, where large particles sink out of the eddies before they dissolve while small particles dissolve near the surface. We then release calcite, with a dissolution rate which depends on the calcite saturation of the water, across a front between strongly undersaturated water and water which is close to saturation.

First we check we have the dependencies installed

Hydrated lime

DissolvingParticles are spheres whose radius shrinks at a dissolution_rate, and which sink at a sinking_speed. By default the radius shrinks at a constant rate and the particles sink according to Stokes' law, so they slow down as they dissolve. Both can instead be functions of the particle properties and the model fields at the particle, see DissolvingMineral. The default mineral is calcium hydroxide, which releases two moles of alkalinity per mole dissolved.

n = 1000

particles = DissolvingParticles(n; grid)
1000 BiogeochemicalParticles with DissolvingMineral{Float64} biogeochemistry:
├── fields: (:r, :sinking_speed)
└── coupled tracers: (:Alk,)

The particles start with zero radius, so they do nothing until we release them.

We couple the particles to a carbonate system without any biology, which has the alkalinity (Alk) tracer that the particles release, and dissolved inorganic carbon (DIC)

biogeochemistry = NutrientsPlanktonDetritus(grid; inorganic_carbon = CarbonateSystem(), particles)

model = NonhydrostaticModel(grid; biogeochemistry, advection = WENO(order = 5))

Release

Now we release the particles in a 16 m wide patch at the surface, with radii between 20 and 80 μm.

Each computational particle stands for many real particles, the number of which is set by the scalefactors. Here we release 1 kg of lime per metre in the (flat) y direction.

r₀ = 20e-6 .+ 60e-6 * rand(n)
x₀ = 24 .+ 16 * rand(n)
z₀ = - rand(n)

mineral = particles.biogeochemistry

scalefactor = 1 / (mineral.density * 4π / 3 * sum(r₀.^3)) # 1 kg / total particle mass

set!(particles, r = r₀, x = x₀, z = z₀, scalefactors = scalefactor)

release_time = time(simulation)
1800.0

Diagnosing the pH

The pH is not a model variable, so we diagnose it from the carbonate chemistry with a KernelFunctionOperation, which is computed in every cell when it is saved. The model has no temperature or salinity, so we choose constant values of 10 °C and 35.

carbon_chemistry = CarbonChemistry()

@inline total_scale_pH(i, j, k, grid, carbon_chemistry, DIC, Alk, T, S) =
    @inbounds carbon_chemistry(; DIC = DIC[i, j, k], Alk = Alk[i, j, k], T, S, output = Val(:pHᵗ))

(; DIC, Alk) = model.tracers

pH = KernelFunctionOperation{Center, Center, Center}(total_scale_pH, grid, carbon_chemistry, DIC, Alk, 10.0, 35.0)

function particle_output(filename)
    file = jldopen(filename)
    states = [file["timeseries/particles/$iteration"] for iteration in keys(file["timeseries/t"])]
    close(file)

    return (stack(getproperty.(states, name)) for name in (:x, :z, :r))
end

To see how the turbulence changes where the particles dissolve, we compare the depth at which each particle finished dissolving with the depth it would reach in still water. A particle sinking at the Stokes' law speed, $w ∝ r²$, while its radius shrinks at a constant rate $k$, sinks $|w(r₀)| r₀ / 3k$ before it has dissolved.

dissolution_depth = [-z[p, findfirst(iszero, r[p, :])] for p in 1:n]

k = mineral.dissolution_rate

still_water_depth(r) = - mineral.sinking_speed(mineral, (; r), nothing) * r / 3k

We also check that the alkalinity lost from the particles is gained by the water

θ = mineral.released_tracers.Alk # mol Alk / mol mineral

mineral_concentration = 1000 * mineral.density / mineral.molar_mass # mmol / m³

particle_alkalinity = scalefactor * θ * mineral_concentration * 4π / 3 * vec(sum(r.^3, dims = 1))
dissolved_alkalinity = interior(total_Alk, 1, 1, 1, :) .- total_Alk[1, 1, 1, 1]

Calcite with saturation dependent dissolution

Calcite only dissolves in water which is undersaturated, and as it dissolves it raises the saturation state of the water around it. The calcite saturation state, Ω, is computed from the dissolved inorganic carbon and alkalinity by CarbonChemistry, at the same constant temperature and salinity as the pH.

@inline calcite_saturation(carbon_chemistry, DIC, Alk) =
    calcium_carbonate_saturation(carbon_chemistry; DIC, Alk, T = 10.0, S = 35.0)
calcite_saturation (generic function with 1 method)

The dissolution_rate of a DissolvingMineral can be any function of the mineral, the particle's fields, and the required_fields of the model at the particle. Here the radius shrinks at a rate proportional to the undersaturation, 1 - Ω.

struct SaturationLimitedDissolution{C, FT}
    carbon_chemistry :: C
        maximum_rate :: FT # m/s
end

@inline function (dissolution::SaturationLimitedDissolution)(mineral, particle_fields, tracer_fields)
    Ω = calcite_saturation(dissolution.carbon_chemistry, tracer_fields.DIC, tracer_fields.Alk)

    return dissolution.maximum_rate * max(0, 1 - Ω)
end

calcite = DissolvingMineral(density = 2710,
                            molar_mass = 100.09e-3,
                            released_tracers = (; DIC = 1, Alk = 2),
                            dissolution_rate = SaturationLimitedDissolution(carbon_chemistry, 4e-8),
                            required_fields = (:DIC, :Alk))

The particles released into the undersaturated water dissolve as they sink, while those released close to saturation dissolve much more slowly, and the largest reach the bottom. We can see this in the radius of each particle, and in the fraction of the calcite released on each side of the front which is left.
